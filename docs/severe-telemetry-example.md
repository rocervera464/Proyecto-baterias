# Prueba con el CSV de degradación severa

Archivo proporcionado por el usuario, copiado sin modificar a `data/samples/voltscope_bateria_degradacion_severa.csv`. Contiene 301 mediciones entre 0 y 300 segundos, en cuatro columnas: tiempo, voltaje, corriente y temperatura. El archivo no incluye ciclo, temperatura ambiente, voltaje de corte, nivel de medición, química ni capacidad de referencia. Su nombre no demuestra degradación severa ni aporta una etiqueta real de SoH.

Se reprodujo el aviso de la captura con los parámetros iniciales de la interfaz (ciclo 1, ambiente 4 °C, corte 2,2 V, nivel y química desconocidos): la importación funciona, pero el modo estricto se abstiene con 22 características fuera del rango observado. En modo exploratorio, las mismas entradas producen una respuesta HTTP 200, con aproximadamente 63,98 % de SoH. Este porcentaje depende de los parámetros generales y carece de validación para estas condiciones; no se presenta como referencia real del archivo. No deben confundirse las temperaturas medidas en la celda con la temperatura ambiente del ensayo.

La interfaz ahora trata este caso como una incompatibilidad pendiente, en vez de un fallo de lectura o del servicio. Ofrece el botón «Obtener estimación exploratoria», que reenvía exactamente las mismas mediciones y parámetros cambiando únicamente el modo para esa ejecución. Se conservan las advertencias de importación, la comprobación del dominio y las restricciones de recomendaciones de segunda vida. El aviso previo ya no afirma que existe una estimación exploratoria antes de calcularla.

Si el usuario edita los datos, cambia de fuente o carga otro archivo, se retira el botón de reintento anterior para evitar analizar una captura obsoleta. Se puede volver a enviar el formulario para evaluar las entradas nuevas. Los errores de validación de datos y de conexión mantienen su tratamiento de error; no se convierten automáticamente en estimaciones exploratorias.

Verificación: el archivo real pasa por el conversor CSV del frontend y la API en una prueba de regresión. Se verifica la abstención estricta, la respuesta exploratoria con cinco valores finitos y no crecientes y la conservación del informe de incompatibilidad. No se alteran las mediciones ni se fuerza un porcentaje de salud para que coincida con el nombre del archivo. Validación visual interactiva pendiente.
